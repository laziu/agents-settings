# Frontend UI

Follow the project's design system and component library first.
When a dedicated design Skill such as `impeccable` is also loaded, follow its visual direction and commands; the copy rules below still apply.

## Copy

- Never add intros, subtitles, captions, or helper text that restate a heading, label, or control, or describe what the screen does
- Explain only where a user would otherwise get stuck: one short sentence next to the control it explains
- No marketing tone, slogans, emoji, or invented testimonials, metrics, or logos on working screens; report placeholder content
- Keep existing product copy; propose removals instead of deleting it
- Before finishing, remove each non-label sentence you added; restore it only if the screen becomes harder to use

## Visual Defaults to Avoid

Unless the design system or brief asks for them:

- Eyebrow or tracked-uppercase labels above headings
- Gradient text, decorative glass, blur, or glows
- Grids of identical icon-heading-text cards, nested cards, hero-metric blocks
- Thick colored side borders on cards, callouts, or alerts
- Emoji or Unicode glyphs as icons; section numbers that are not a real sequence
- Pulsing badges or motion that carries no state
